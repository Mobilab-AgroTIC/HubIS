Ci-dessus les fichiers d'impression 3d pour créer des accessoires sur tube PVC (diamètre 40 (intérieur 36.2)).
Les fichiers .3mf sont prêts à être importé dans le slicer de votre choix

Le fichier .FCStd permet de modifier les dimensions des accessoires pour s'adapter à votre tuyau (diamètre 50 par exemple ou un tube en diamètre 40 mais dont le diamètre interne est différent)
- Téléchargez [FreeCAD]([url](https://www.freecad.org/downloads.php?lang=fr))
- Dans le menu de gauche avec toutes les fonctions de modélisation 3D, en bas vous trouvez un "Sprezdsheet". C'est ici que vous pouvez modifier les paramètres
- Une fois les paramètres modifiés, cliquez sur Fichier>Exporter pour récupérer votre objet à slicer en .stl ou .3mf
